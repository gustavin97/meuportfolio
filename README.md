# Dev Guz Portfolio

Portfólio pessoal desenvolvido para apresentar minha trajetória como desenvolvedor, tecnologias utilizadas, projetos realizados e experiências na área de desenvolvimento web.

## Sobre o Projeto

Este projeto foi criado com o objetivo de servir como:

* Portfólio profissional
* Apresentação para recrutadores
* Vitrine de projetos e estudos
* Laboratório para práticas de front-end moderno
* Ambiente para experimentação com animações e experiências imersivas
